8-Bit Pipelined Arithmetic Logic Unit (ALU) Using Verilog HDL Project Overview : This project focuses on the Design and Implementation of an 8-Bit Pipelined Arithmetic Logic Unit (ALU) using Verilog HDL. An Arithmetic Logic Unit (ALU) is an essential component of a processor that performs arithmetic and logical operations. This project implements an 8-bit ALU using a two-stage pipelined architecture with an accumulator and load registers. The design supports five basic operations: Addition, Subtraction, AND, OR, and XOR. The functionality is verified through Verilog testbench simulation using Xilinx Vivado.

Objectives: To design an 8-bit Arithmetic Logic Unit using Verilog HDL. To implement a two-stage pipelined architecture. To perform arithmetic and logical operations. To implement load registers and an accumulator. To verify the functionality using a Verilog testbench. To perform simulation and synthesis using Xilinx Vivado. To prepare the design for implementation on an Artix-7 FPGA.

Features: 8-bit data processing. Two-stage pipelined architecture. Synchronous reset. Operand loading registers. Accumulator for storing running results. Five arithmetic and logical operations. Valid signal generation for pipeline stages. Behavioral simulation using Xilinx Vivado.

Supported ALU Operations: The ALU supports the following operations using a 3-bit operation selector (alu_sel). Operation Code Operation Description 000 ADD Addition (A + B) 001 SUB Subtraction (A - B) 010 AND Bitwise AND 011 OR Bitwise OR 100 XOR Bitwise XOR

Architecture: The project consists of the following functional blocks: Input Section: Accepts two 8-bit operands (data_in and operand_b) and a 3-bit operation selector (alu_sel). Load Registers: Store the input operands when load_en is enabled. Pipeline Stage 1: Captures the operands and operation selector when the start signal is enabled. Combinational ALU: Performs the selected arithmetic or logical operation. Pipeline Stage 2: Registers the ALU output and generates the corresponding valid signal. Accumulator: Adds valid ALU results to the previously stored accumulator value when acc_en is enabled. Output Section: Provides the final ALU result and result-valid signal. Pipeline Flow Input Operands → Load Registers → Pipeline Stage 1 → Combinational ALU → Pipeline Stage 2 → Output The accumulator operates separately and stores the accumulated results.

Hardware and Software Requirements: Hardware Requirements Artix-7 FPGA development board. Computer or laptop. Software Requirements Xilinx Vivado 2026.1. Verilog HDL. XSim Simulator. Target FPGA xa7a12tcpg238-2I

Vivado Implementation Workflow: The following steps were performed using Xilinx Vivado: Created a new Vivado project. Selected the target Artix-7 FPGA device. Added the main Verilog design file. Added the Verilog testbench. Performed behavioral simulation using XSim. Verified the outputs of all five ALU operations. Performed RTL synthesis. Prepared the XDC constraints file for FPGA implementation.
